# Estudio Cardozo · posteos

Imágenes de los posteos de redes de Estudio Cardozo (Cipolletti, desde 1993).
Metricool las toma desde acá para publicarlas en Instagram, Facebook y Google.

Una carpeta por mes: `posteos/AAAA-MM/`. No borrar imágenes de posteos ya programados.

## Cómo se genera

- `CONTENIDO.md`: guía editorial, fuentes oficiales y formato de cada lote.
- `tools/build.py`: genera las imágenes de un lote (`python3 tools/build.py posteos/AAAA-MM/lote.json`).
- `tools/marca/`: logo, colores y estilos del manual de marca. `tools/fonts/`: Newsreader y Manrope (licencia OFL).
